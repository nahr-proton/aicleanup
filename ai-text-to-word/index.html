Background

Why AI text breaks in Word

Assistants write in markdown, a plain text convention where a hash mark means heading and a pair of asterisks means bold. The chat window quietly renders those symbols into real formatting, so what you see on screen looks like a finished document.

The symbols are still in the text. When you copy it out, you take them with you. Word has no idea what they mean, so a heading arrives as ## Section title and every bold phrase arrives wrapped in literal asterisks. The structure that made the answer readable is now visible clutter, and you end up reformatting the whole thing by hand.

This tool reads the markdown the way the chat window does, then rebuilds it using genuine Word constructs. Headings become real heading styles, which means they show up in the navigation pane and in any table of contents you insert. Lists become real lists that renumber themselves. Tables become real tables you can sort. Code blocks get a monospaced font and a light background so they stay readable.

FAQ

Questions

Why does ChatGPT text paste into Word with asterisks everywhere?

The assistant writes in markdown, where asterisks mean bold and hash marks mean headings. The chat window renders those symbols into real formatting, but the underlying text still contains them. Word does not understand markdown, so when you paste you get the raw symbols instead of the formatting they stand for.

What formatting is preserved in the Word file?

Headings one to four become real Word heading styles, so they appear in the navigation pane and any table of contents you insert. Bold, italic and strikethrough are kept, along with bullet lists, numbered lists, tables, blockquotes, links and code blocks, which are set in a monospaced font on a light grey background.

Can I edit the document afterwards?

Yes. The result is an ordinary .docx file with real Word styles, not an image or a locked export. It opens in Microsoft Word, Google Docs, LibreOffice and Pages, and everything in it can be edited normally.

What do the clean up options do?

They tidy the giveaway marks of AI writing before the document is built. Em dashes can be replaced with commas, curly quotes converted to straight ones, and emoji removed. All three are optional and off by default, so the text is converted exactly as pasted unless you ask otherwise.

Is my text uploaded anywhere?

No. The markdown is parsed and the Word file is assembled in your browser. The document is created on your own device and never sent to a server, stored or logged.
