Background

Why markdown breaks in a CMS

Markdown and HTML solve the same problem in different alphabets. In markdown a heading is a line beginning with a hash mark; in HTML it is text wrapped in an <h1> tag. Chat windows read the first and display the second, which is why the answer looks formatted on screen.

Your CMS never sees that translation. Paste markdown into WordPress, Ghost, Webflow or an email builder and it takes the symbols literally, so readers get hash marks and asterisks scattered through the text instead of headings and bold phrases.

Converting first hands over tags the CMS already understands. The fiddly part is doing it safely: any stray angle bracket in the original has to become visible text rather than live markup, or you end up publishing something you did not write. That escaping is handled here, and links are checked so that only ordinary web addresses become clickable.

FAQ

Questions

Why does markdown not work in my CMS?

Most content management systems expect HTML, not markdown. Pasting markdown into one gives you literal hash marks and asterisks on the page, because nothing has translated those symbols into headings and bold text. Converting to HTML first hands the CMS the tags it actually understands.

Should I use the fragment or the full document option?

Use the fragment, which is the default, when you are pasting into something that already has a page around it, such as a CMS editor, a newsletter tool or a template. Use the full document option when you want a standalone .html file you can open in a browser, since it adds the doctype, character set and title.

Is the HTML safe to publish?

Yes. All text is escaped as it is written out, so anything that looks like a tag in your source becomes visible text rather than live markup. Links are checked against a list of allowed schemes, so a javascript: or data: URL never becomes a working link. This matters when the markdown came from an AI assistant that may have repeated content from elsewhere.

What formatting is supported?

Headings one to six, paragraphs, bold, italic, strikethrough, inline code, links, images, bullet and numbered lists including one level of nesting, tables with column alignment, blockquotes, horizontal rules and fenced code blocks with a language class.

Is my text uploaded anywhere?

No. The markdown is parsed and the HTML is built in your browser. Nothing is sent to a server, stored or logged.
