Background

Why AI tables break in Excel

What looks like a tidy table in a chat window is not a table at all. It is plain text, drawn with pipe characters and dashes, in a format called markdown. The chat interface renders those characters into neat lines and columns, so on screen it looks finished.

Excel has never heard of markdown. When you paste, it sees ordinary text with no column separator it recognises, because a pipe is not one of the characters it splits on. Every row is dropped into a single cell, pipes and all, and you get one tall column of rubbish instead of a grid.

The fix is to read the markdown properly, work out where the columns actually are, and hand Excel something it understands: either a real .xlsx file, a comma separated file, or tab separated text, which is the one format spreadsheets will split into cells automatically when you paste. This tool does that, including the fiddly parts such as escaped pipes inside cells and bold text that should not survive the trip.

FAQ

Questions

Why does a ChatGPT table paste into Excel as one long column?

A markdown table is plain text. The pipe characters draw the columns for a human reader, but Excel does not treat a pipe as a column separator, so every row lands in a single cell. The table has to be converted into a real grid first, which is what this tool does.

What if my paste contains more than one table?

Every table in the text is found and previewed. The .xlsx download places each table on its own worksheet, named Table 1, Table 2 and so on. For CSV and tab separated copies, which hold only one grid each, a picker appears so you can choose which table to export.

What happens to bold text, links and code inside cells?

The markdown syntax is removed and the text is kept. Bold becomes plain text, inline code loses its backticks, and a link keeps its visible label rather than the URL. Escaped pipes inside a cell stay as pipe characters instead of splitting the column.

Should I use xlsx, csv or tab separated?

Use .xlsx for Excel, especially with several tables, because each one becomes a worksheet. Use .csv for importing into other software. Use the tab separated copy when you want to paste directly into a sheet that is already open in Excel or Google Sheets, since it fills the cells immediately with no import step.

Is my table uploaded anywhere?

No. Parsing and file creation happen in your browser. The spreadsheet file is built on your own device and never sent to a server. Your data is never stored or logged.
